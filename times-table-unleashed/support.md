# Times Table Unleashed Support

## Need help?

For help with Times Table Unleashed, email [sockserboxerstudio@gmail.com](mailto:sockserboxerstudio@gmail.com). Please include your device model and iOS version so we can help more quickly.

## About the app

Times Table Unleashed is an offline multiplication-practice game for iPhone and iPad. It does not require an account or sign-in.

## Managing progress

Learning progress is stored on the device. Parents and teachers can use the app's parent controls to manage the learner profile or reset local progress.

Read the [Times Table Unleashed Privacy Policy](/times-table-unleashed/privacy-policy/) for details about the app's data practices.
